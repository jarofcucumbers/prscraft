# PRSCraft — телекомунікації для Minecraft

Початкова версія для **Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21**.

## Збірка та запуск

```sh
./gradlew build
./gradlew runClient
# Виділений сервер (потрібне власне прийняття Minecraft EULA у run/eula.txt):
./gradlew runServer
```

Готовий мод: `build/libs/prscraft-0.1.0.jar`. Встановіть його до `mods` клієнта та сервера з NeoForge. Додаткові моди не потрібні. Тести: `./gradlew test`.

## Як спробувати

У творчому режимі відкрийте вкладку PRSCraft. Вона містить передавач та коаксіальний, оптоволоконний і металевий порти. Рецептів виживання поки немає.

1. Поставте передавач і пряму лінію однакових портів впритул до нього. Один блок відповідає одному метру; ліміт пошуку — 64 блоки. Повороти, розгалуження та змішування типів поки не підтримуються.
2. Порожньою рукою натисніть ПКМ на передавач: перемикання 100 / 125 / 150 / 175 МГц. Shift + ПКМ вмикає та вимикає передавач. Потужність фіксована: 20 dBm (100 мВт). Налаштування зберігаються у стані блока.
3. Порожньою рукою натисніть ПКМ на порт: повідомлення містить довжину, потужність прийнятого сигналу та SNR. Несумісний блок чи розрив зупиняє лінію.
4. Поставте другий увімкнений передавач у радіусі 4 блоків від порту. Його канал і тип лінії впливають на оцінку перешкод; оптоволокно не підхоплює електромагнітні перешкоди.

## Спрощена фізика першої версії

| Лінія | Втрати на 100 МГц | Втрати роз'єму | Коефіцієнт наведення |
|---|---:|---:|---:|
| Коаксіальна | 0,20 dB/м | 1 dB | 0,05 |
| Оптоволоконна | 0,003 dB/м | 0,5 dB | 0 |
| Металева | 0,50 dB/м | 2 dB | 0,35 |

`RX = 20 dBm − втрати роз'єму − довжина × втрати/м × sqrt(частота/100)`.
Для волокна частотний множник дорівнює 1: тут це умовна лінія з електрооптичним перетворювачем, а не безпосереднє поширення радіохвилі у склі. Значення демонстраційні, не специфікація конкретного кабелю.

Канали мають умовну ширину 40 МГц; перекриття спектрів визначає наведення. Потужності перешкод додаються у лінійній шкалі, фоновий шум — −90 dBm. Геометрія стін, справжнє екранування, бездротове поширення, відбиття, пропускна здатність, живлення та передавання даних ще не реалізовані. Обчислення виконується при взаємодії, не кожен тик; незавантажені чанки не завантажуються примусово.

## Моделі

Згенеровано чотири редаговані Minecraft JSON-моделі в `src/main/resources/assets/prscraft/models/block`: корпус передавача з дисплеєм та антеною і три кольорові моделі роз'ємів. Використовуються стандартні текстури Minecraft, тому окремі PNG та бібліотеки рендерингу не потрібні. Моделі можна імпортувати до Blockbench як Java Block/Item. Порти наразі є сегментами прямої лінії; гнучкі кабелі між роз'ємами — наступний етап.
