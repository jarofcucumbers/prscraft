# PRSCraft development

Use the existing checkout. Java 21, Minecraft 1.21.1, NeoForge 21.1.264; build with `./gradlew build`, integration checks with `./gradlew runGameTestServer`.

Every user-facing feature or behavior change MUST update the in-game handbook: `HandbookContent.java`, the `book.prscraft.*` translations in both `en_us.json` and `uk_ua.json`, and relevant diagrams/formulas in `HandbookScreen.java`. Keep the handbook version equal to the mod version. Add every new block/item to handbook coverage; the integration test checks this. Explain signal units, assumptions and simulation limits honestly. Keep README usage examples current.

Preserve backwards-compatible NBT defaults for existing worlds, templates and recordings. Server-side settings validation and read-only analyzer behavior are required. Keep PSD/ESD normalization consistent with Parseval and distinguish finite-window metrics from whole-signal energy. Q-based AWGN theory is a symbol-space model and must not be advertised as an exact BER prediction for arbitrary nonlinear RF chains.

When delivering a new release, build and validate the JAR, exclude GameTest fixtures, copy it and its SHA-256 into `releases/`. Never claim interactive UI validation unless it was actually run.

Signal computation is authoritative in `CircuitCapture`/`CircuitNetwork`; analyzer topology is deliberately undirected and spans active devices. Keep A=back, B=left, OUT=front consistent in code, models and handbook. Apply cable segment losses/noise before the next DSP stage. Integrator/correlation dimensions must never be silently exported as W/J spectra. Custom pose-scaled screens use `ScaledButton`, not vanilla scrolling buttons (scissors ignore the outer pose in 1.21.1).

Drawing boards use server-authoritative palette bytes (128×128, 0=blank), shared by editor and block renderer. Charge actual tool durability even in creative; the eraser stays at max damage and only a water-cauldron wash restores it. Recoloring chalk must preserve components/wear. Keep world, dropped-item and client-sync canvas persistence tested. Unipolar URZ power/energy normalization includes duty; receiver A1 is a manually configured received amplitude. Handbook formula legends (`.symbols`) and challenge conditions must be updated in both languages.

Gray conversion is MSB-first, capture-aligned and limited to 128 output bits; ADC index encoding uses measured input and calibrated min/max, never source metadata. Keep Gray templates/recordings/NBT defaults tested. Port FACING is cosmetic mounting (six faces), independent of passive connectivity; processor A/B/OUT directions must match models, analyzer and engine in every horizontal orientation.

Handbook navigation is defined in assets/prscraft/handbook/curriculum.json: foundations, catalog entries covering every item, and one task per advancement. Task solutions, nodes, and configuration must remain hidden until explicit reveal; never persist revealed answers in bookmarks. Keep both translations and schematic parameters current. The client bookmark uses stable entry IDs and per-player atomic JSON storage. Board figure/text previews and commits share BoardDrawing geometry; payloads are bounded 16384-bit masks and each unique touched pixel consumes durability. Inset equipment must not occlude adjacent full-cube terrain faces.

Analyzer map edges retain attachment roles and physical buses; possible flow arrows must be distinguished from the selected CircuitCapture.signalEdges route. Directed layout groups cycles before layering. Map zoom must anchor at the cursor; fitting must include all ≤32 reported devices, and clipping must use outer GUI coordinates rather than pose-local scissors.

Full messages use BitStream (MSB first, exact meaningful bit length, ≤32768 bits) independent of 512-point/128-bit preview. Source limit is 1024 UTF-8/Hex bytes. Apply cable/front-end noise before actual decisions and never reconstruct from original comparison metadata. Compression containers transmit and count their dictionary/header. CRC detects; Hamming(7,4) corrects one error per word and may miscorrect doubles. Custom codebook cards are prefix-free Unicode scalar mappings in media slot 2; RX without a local card must not interpret custom bits as text, including byte-aligned codes. Preserve legacy two-slot inventory contents during migration. Byte codecs reject non-byte-aligned custom streams. Full-message unsupported DSP stages fail explicitly. PlotSettings are display-only, persisted on devices/templates and local-only in analyzer/recording views. Handbook large-text subpages persist in bookmarks while revealed solutions do not. Bulk eraser costs ceil(paintedPixels×1.1), atomically fails if charge is insufficient, and never charges blank pixels.

0.9 circuits share CircuitAccess between Level and SimulatorDocument.World; keep virtual/physical results identical given equal settings/routes. Virtual node layout never sets cable length. Simulator mutations require a nearby physical workstation and commit atomically with a 512 KiB document cap; virtual requests must never fall through to world positions. Preserve virtual codebook/template/capture and board data in block/item NBT. Virtual weather is controlled and arbitrary node IDs must not induce spatial interference. Lab-coat HUD is read-only, chest-equipped and server-distance validated. Notebook entries deep-copy actual captures and templates; notes never mutate recorded data, eight entries maximum, physical template creation consumes paper.

PacketCodec uses fixed padded slots with received CRC-protected headers; payload size is agreed. Initial batch ARQ repeats the complete buffered batch and counts every retransmitted frame, deduplicates received sequence numbers, and distinguishes delivery from ACK confirmation. Retry limit/timeout belong to sender; receiver controls modeled independent ACK loss. Retry noise must be fresh downstream of the buffered sender; never replace data from original comparison metadata. IqSignal normalizes uniform QPSK/Gray 16-QAM to mean Es=1 in relative symbol space, with noise variance per quadrature and known coherent phase/clock. Preserve meaningful bit length with final-symbol padding; hard-decision previews are not RF power waveforms. Orthogonality is a finite-window normalized inner product with explicit tolerance/energy/resolution validity; requested windows expand the shared capture and respect source Nyquist resolution. Cable dispersion is a causal one-pole approximation before the next stage, including I/Q; document simplified weather/local interference coefficients and retain zero-dispersion legacy defaults.
